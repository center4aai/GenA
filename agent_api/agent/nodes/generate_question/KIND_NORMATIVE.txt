### ИНСТРУКЦИИ ПО ТИПУ ДОКУМЕНТА: нормативно-правовой документ

1. Отсылка к источнику в тексте вопроса ОБЯЗАТЕЛЬНА.
2. При отсылке всегда указывай ПОЛНОЕ название источника (например: «согласно статье 5 УК РФ», «согласно статье 2 Конституции Российской Федерации»). Нельзя писать только «согласно 1 главе» или «согласно статье 5» без названия документа.
   Если в вопросе есть отсылка к источнику (например, «...согласно 1 главе», «...согласно Статье 3», «...согласно ФЗ-172»), то ОБЯЗАТЕЛЬНО используйте информацию из поля «Источник» для полной формулировки. Например, вместо «...согласно 1 главе» должно быть «...согласно 1 главе Конституции РФ», где «Конституция РФ» берётся из поля «Источник». Всегда указывайте полное название источника при отсылках к нему.
3. Сам исходный текст чанка НЕЛЬЗЯ включать в вопрос: вопрос должен быть понятен отвечающему без чтения исходного фрагмента. Строго избегай формулировок вроде «согласно приведённому тексту», «согласно указанному тексту», «согласно тексту», «по тексту», «в тексте» (без названия документа), «описанный в тексте», «упомянутый в тексте» и подобных отсылок к самому чанку.
