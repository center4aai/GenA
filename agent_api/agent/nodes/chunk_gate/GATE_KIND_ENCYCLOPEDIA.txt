ВЫСТАВИ c2 = 0 ТОЛЬКО ЕСЛИ: ЧАНК НАЧИНАЕТСЯ С ОБРЫВКА ПРЕДЛОЖЕНИЯ; ЧАНК ОБРЫВАЕТСЯ НА СЕРЕДИНЕ ПРЕДЛОЖЕНИЯ; ПРЕДМЕТ СТАТЬИ НЕ НАЗВАН НИГДЕ В ЧАНКЕ; ТЕКСТ ЯВНО ССЫЛАЕТСЯ НА ТО, ЧЕГО В ЧАНКЕ НЕТ («СМ. ТАБЛ. ВЫШЕ», «СМ. КАРТУ»).
